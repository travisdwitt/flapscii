# FlapSCII
A rather violent flappy bird clone

<img width="580" height="414" alt="menu" src="https://raw.githubusercontent.com/travisdwitt/flapscii/refs/heads/main/menuDemo.gif" />

```bash
go build -o flapscii
./flapscii
```

## Controls

- **SPACE**: flap
- **ESC**: quit
